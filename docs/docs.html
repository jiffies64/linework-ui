01

Quick start

Link the sheet, load the behaviour, write markup. No configuration file, no build step, no framework.

1

Link the stylesheet

One file carries tokens, layout, components and utilities. Load the minified build in production.

2

Load the behaviour

Only the interactive parts: drawers, tabs, pads, meters, menus and toasts. CSS-only components work without it.

3

Use the class, or the element

Markup is plain HTML. Use lw-pad when you want behaviour; use .lw-btn when you do not.

HTML — a complete sheet 
<!doctype html>
<html lang="en" data-theme="trace">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="linework.css">
  <script src="linework.global.js" defer></script>
</head>
<body class="lw-graph">
  <main class="lw-wrap" style="padding: 48px">
    <h1 class="lw-display">Drawn to scale.</h1>
    <button class="lw-btn lw-btn--primary">New sheet</button>
    <lw-pad name="Publish" keys="1" length="1.2 s"></lw-pad>
  </main>
</body>
</html>
No build step required. If you do use a bundler, import linework-ui/style.css and linework-ui. Both paths are real files in the package. Nothing is injected at runtime except the icon sprite and toasts.
02

Files & install

The kit is deliberately small. These are the only files you need to understand.

Download the two files from the CSS and JavaScript, or vendor the package. The blocks page additionally loads linework-blocks.css for the composed section layouts.

linework.min.cssThe same sheet with comments and whitespace removed. 68.7 kB raw / 11.8 kB gzipped.Production.
tokens.cssOnly the custom properties, for teams with their own CSS.You are bringing your own rules.

Package — imports
// CSS (pick one)
import 'linework-ui/style.css';
import 'linework-ui/min.css';

// Behaviour (ES module)
import Linework from 'linework-ui';

// Optional blocks
import 'linework-ui/blocks.css';
Serving locally? The documentation and previews are static files. Run npm start at the repository root, or open the pages through any static server. file:// works for the global build, but clipboard access may be restricted by the browser.
03

Tokens

Every colour, type size, space, border and duration is a custom property on :root.

Override tokens in your own stylesheet. Do not override component internals unless you are changing a rule deliberately. Tokens are the contract.

CSS — a private paper
:root {
  --lw-paper: #f4f1e8;
  --lw-paper-lit: #fbf8f0;
  --lw-ink: #1e1c18;
  --lw-pencil: #5c5549;
  --lw-redline: #c53a2a;
  --lw-redline-deep: #9b2b1f;

  --lw-font-ui: "Barlow Semi Condensed",
    "Segoe UI", system-ui, sans-serif;
  --lw-radius: 0; /* please keep it */
}
TokenRole
--lw-paperSheet background; the default surface.
--lw-inkGraphite text, borders, filled keys.
--lw-pencilSecondary text; readable but quiet.
--lw-ruleHairline rules and quiet borders.
--lw-gridThe 24 px graph-paper line.
--lw-redlineLive, playing, destructive, focus.
--lw-font-uiBahnschrift-first interface stack.
--lw-space-88 px. The scale is named in pixels.
--lw-duration-2140 ms, the standard interaction.
--lw-focus-width1.5 px dashed construction line.
Spacing is named by value: --lw-space-2 is 2 px, --lw-space-14 is 14 px, and so on. That makes the CSS readable without a lookup table.
04

Papers & theming

Three papers ship in the box: trace, blueprint and vellum. Apply one with data-theme on the root, or on any container if only one figure should change paper.

Trace — defaultdata-theme="trace"
On air Live
Blueprint — darkdata-theme="blueprint"
On air Live
Vellum — warmdata-theme="vellum"
On air Live

Set the paper on the root for a whole application; set it on a figure when one Figure should be a blueprint. The tokens cascade, so a nested theme is a complete, local change.

JavaScript — remember the paper
import Linework from 'linework-ui';

// Reads/writes data-theme and remembers the choice.
Linework.setTheme('blueprint');
Linework.getTheme();        // "blueprint"
Linework.cycleTheme();      // next paper

// Buttons can do it declaratively:
// <button data-lw-theme="blueprint">
// <button data-lw-theme="cycle">
Redline is a rule, not a variable. A custom theme can change the hue to your brand, but it should still mean live, playing or destructive. If everything is red, nothing is.
Persistence: the theme button/API stores the choice in localStorage under linework-theme. Pass { persist: false } for a one-off preview.
05

Typography

Bahnschrift is the native voice of a technical drawing. The stack falls back through DIN Alternate and modern grotesques when it is not installed.

The UI uses Bahnschrift first; it ships with Windows 10 and 11. macOS has DIN Alternate. For a consistent cross-platform look, load an open DIN-like face such as Barlow Semi Condensed and put it at the front of --lw-font-ui.

CSS — an open substitute
@import url("https://fonts.googleapis.com/css2?family=Barlow+Semi+Condensed:wght@300;400;500;600;700&display=swap");

:root {
  --lw-font-ui: "Barlow Semi Condensed", Bahnschrift,
    "Segoe UI", system-ui, sans-serif;
  --lw-font-display: "Barlow Semi Condensed", Bahnschrift,
    "Helvetica Neue", sans-serif;
}
  • Display and titles use the display stack at weight 300, tracked slightly tight. Never use display type below 24 px.
  • Labels use the narrow stack, uppercase, 0.12 em tracking, at 11 px.
  • Body is 14–17 px with a 1.55 line height. Long reading caps at about 72 characters.
  • Figures use the monospace stack with tabular numerals so columns of dimensions line up.
Fonts are not bundled. Bahnschrift and DIN Alternate are system fonts; Barlow is open source under the SIL Open Font License.

Web components

Five small custom elements cover the things markup cannot do alone. Everything else is a class. All five use light DOM, so your CSS still reaches inside.

        keys="1"

<script>
  const pad = document.querySelector('lw-pad');

  pad.addEventListener('lw-press', (event) => {
    // Take over the operation. Without preventDefault,
    // the pad runs its own visual timer.
    event.preventDefault();
    pad.play(1.2);
  });
</script>

Events

lw-press is cancelable and bubbles before anything happens. lw-play, lw-stop and lw-end describe the pad lifecycle. lw-open and lw-close fire on drawers; lw-change fires on tabs.

08

Frameworks

The CSS is framework-agnostic. The five custom elements are standard; use them as tags in every modern framework, or just use the classes.

React — a pad wrapper
import { useEffect, useRef } from 'react';
import 'linework-ui/style.css';
import Linework from 'linework-ui';

export function ActionPad({ item }) {
  const ref = useRef(null);

  useEffect(() => {
    Linework.icons.install();
    const pad = ref.current;
    const onPress = () => {
      // drive your own operation here
    };
    pad?.addEventListener('lw-press', onPress);
    return () => pad?.removeEventListener('lw-press', onPress);
  }, []);

  return <lw-pad ref={ref} name={item.name}
                 keys={item.keys} />;
}

React 19 passes custom-element props through as properties; React 18 stringifies them as attributes, which is exactly what Linework reads. For events, attach listeners to a ref, or wrap the element in a small component as above.

  • Vue: use <lw-pad :name="item.name" @lw-press="run">. Add compilerOptions.isCustomElement for the lw- prefix to silence warnings.
  • Svelte: custom elements are native tags; bind events with on:lw-press in Svelte 4 or onlw-press in Svelte 5.
  • Astro: render the tags as static HTML and load the global script once in the layout. The components enhance on the client.
SSR: importing linework-ui is guarded for Node; the custom elements register only in a browser. The tags render as unknown elements on the server and upgrade after hydration.
09

Accessibility

Linework starts with native controls and adds the visual layer on top.

Built in

  • Native buttons, inputs, selects, checkboxes, radios and <details>; no div-buttons.
  • Visible keyboard focus: a 1.5 px dashed construction line with an offset.
  • Native modal dialogs for sheets and dialogs: top layer, focus trap, Escape, backdrop.
  • Roving tabindex and Home/End/arrow keys in tabs and menus.
  • Toasts in a polite live region, above native dialogs via popovers, paused on hover or focus.
  • ARIA meters with a value, a label and a non-visual name for icon-only keys.
  • Reduced-motion support for animation and smooth scrolling.
  • AA contrast for body text, labels and controls in all three papers.

Your side of the contract

  • Give every field a real label and every icon-only button an aria-label.
  • Never use redline as the only signal. Pair colour with text, a stamp or a dot.
  • Use the redline for large text and borders; use redline-deep for small red type.
  • Do not remove focus outlines. If you restyle them, keep a 3:1 contrast ring.
  • Test with your own copy, zoom at 200%, and a screen reader once per release.

10

Principles

Six rules for keeping the drawing readable after the first sprint.

  • A line has a job. Hairlines separate. Heavy rules define. Dashed lines mean construction or focus. Remove any line that does none of these.
  • Structure before surface. If the layout needs a gradient to make sense, the layout is not finished.
  • Redline means live. Playing, recording, destructive, focused, pending. Never decoration.
  • Sharp corners, real borders. Elevation is a border and a scrim, never a shadow.
  • Use tokens. If a colour or space appears twice as a literal, it belongs in a token.
  • Native first. Buttons, dialogs, details and inputs already work. Draw them; do not rebuild them.
